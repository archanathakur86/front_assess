
# front_assess

This project is a responsive web interface featuring an animated image and text slider, along with a product grid section. It is designed to closely match Figma design specifications, focusing on pixel-perfect implementation, color, spacing, typography, and visual hierarchy.

## Features

- **Slider:**
	- Animated image and text slides with navigation arrows and dots
	- Auto-slide functionality (every 3.5 seconds)
	- Responsive design for different screen sizes
- **Product Grid:**
	- Displays product cards with brand, title, and pricing
	- Responsive grid layout

## File Structure

- `index.html` — Main HTML file containing the slider and product grid markup
- `style.css` — All styles for layout, slider, and product cards
- `script.js` — JavaScript for slider functionality (navigation, auto-slide)

## Setup & Usage

1. **Clone or Download** this repository/folder.
2. Open `index.html` directly in your web browser.
3. No build tools or server required; all assets are local.

## Customization

- Update product details in the `.products` section of `index.html`.
- Adjust colors, fonts, or layout in `style.css` as needed.

## Project Purpose

This project is intended as a front-end assessment to demonstrate:
- Ability to translate Figma designs into code
- Responsive web development
- Clean, maintainable HTML, CSS, and JavaScript
